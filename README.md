# Anurag — Developer Portfolio

A responsive, premium dark-mode portfolio built with React, Vite, custom CSS, and Lucide icons. Includes project filters, responsive navigation, a light/dark theme toggle, experience, skills, certifications, achievements, and contact links.

## Run locally

Requirements: Node.js 20.19+ or 22.12+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Push this folder to a GitHub repository, then import that repository into Vercel. Vercel detects Vite automatically. See the official [Vite deployment guide](https://vite.dev/guide/static-deploy.html).

## Before publishing

- Confirm the LinkedIn profile URL before publishing.
- Add `public/Anurag-CV.pdf` and update the hero with a CV download link if desired.
- Check each repository and live demo; only the CPU Scheduling Simulator has a live link currently included in this draft.
- Verify the Codolio global rank and DSA totals are still accurate before sharing.
- Replace or revise project descriptions if repository functionality differs from the descriptions shown.
- Add project screenshots from the actual applications when available. Current project visuals are CSS mockups, not screenshots of the deployed applications.
